TANJAKAI - Frontend (Next.js)

Ce dossier contient uniquement le code de l'application : app/, components/, lib/ et .env.local.
Il se pose dans le projet cree par "npx create-next-app" (Next.js 16, TypeScript, Tailwind).

L'interface n'appelle que l'API (NEXT_PUBLIC_API_URL dans .env.local), jamais la base de donnees.
